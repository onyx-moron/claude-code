Antes de dibujar

Fija la retícula una sola vez: unidades por em, alturas y línea base. Cambiarlas después reescala todo lo dibujado.

Element ▸ Font Info ▸ General · em 1000

Importar el trazo

Vectoriza la muestra fuera y trae el contorno limpio, o calca sobre la imagen de fondo en la ventana del glifo.

File ▸ Import · SVG / imagen de fondo

Validar

Contornos abiertos, dirección invertida o extremos faltantes rompen el render. Se revisan de golpe para toda la fuente.

Element ▸ Validation ▸ Find Problems

Generar
